# Temporary Placeholder Audio Assets

The `.ogg` and `.wav` files in `music/`, `ambient/`, and `sfx/` are **temporary placeholder audio assets** extracted locally from `Don't Starve Together` (`tools/extract-dst-audio.py`) for prototyping gameplay audio, bus routing, and adaptive music/ambience layers.

They **must be replaced** with original or properly licensed audio assets before any public distribution or release.
